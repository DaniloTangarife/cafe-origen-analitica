# Café Origen: Analítica de ventas

Proyecto de la ruta de algoritmia (Riwi). Analiza una muestra del historial de ventas de Café Origen usando JavaScript (Node.js).

## Estructura

- `src/datos.js`: arreglo `ventas` con los 12 registros originales.
- `src/explorar.js`: script de exploración de los datos.
- `src/analitica.js`: funciones de análisis (en desarrollo).
- `bitacora.md`: diccionario de datos y casos borde detectados.

## Cómo ejecutar

```bash
node src/explorar.js
```

## Requisitos

- Node.js (versión LTS)
